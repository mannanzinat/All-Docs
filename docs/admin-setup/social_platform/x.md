# X/Twitter Platform Configuration for SocialVibe

## Steps to Configure
1. Navigate to the **Platforms** section in the SocialVibe dashboard and locate the **X/Twitter** platform in the list.
2. Click on the **Settings** button (settings icon) under the "Options" column for the Twitter platform.
3. A modal titled **Update Configuration** will appear, displaying the following fields:
  - **API Key**: Enter the API Key provided by your Twitter Developer account.
  - **API Secret**: Enter the API Secret associated with your Twitter Developer account.
  - **Access Token**: Provide the Access Token obtained from the Twitter Developer account.
  - **Access Token Secret**: Provide the Access Token Secret for your Twitter app.
  - **Client ID**: Enter the Client ID generated by your Twitter Developer account.
  - **Client Secret**: Enter the Client Secret provided for your Twitter app.
  - **App Version**: Specify the API version to be used (e.g., v2).

## Setting Up X (Twitter) Integration for SocialVibe

Twitter uses an OAuth2 flow for most features with its v2 API. However, to upload pictures, the older Twitter v1 API must be used. SocialVibe leverages the normal OAuth1 flow to ensure compatibility with both APIs. Follow these steps to set up the integration:

### Step 1: Create a New App in Twitter Developer Portal
1. Head over to the **Twitter Developer Portal** and log in to your account.
2. Sign up for a new free developer account if you haven’t already.
3. Create a new app in the **Projects & Apps** section.

### Step 2: Configure Your App
1. Navigate to the newly created app and click on the **Settings** icon.
2. In the **User Authentication Settings**, click on **Set Up** and follow these configurations:
  - **App Permission**: Set it to **Read and Write**.
  - **Type of App**: Select **Web App**, **Automated App**, or **Bot**.
  - **Callback URI / Redirect URL**: Enter the following URL:
    ```
    https://socialvibe.spagreen.net/account/twitter/callback?medium=twitter
    ```
3. Save the settings.

### Step 3: OAuth2 Redirect URI
The OAuth2 Redirect URI is the location where Twitter will redirect after authentication. Use the URL specific to your setup:

- **For production**:
  ```
  https://socialvibe.spagreen.net/account/twitter/callback?medium=twitter
  ```
- **For localhost (development)**: Replace `socialvibe.spagreen.net` with your local development URL (e.g., `http://localhost:4200/account/twitter/callback?medium=twitter`).

### Step 4: Obtain Keys and Tokens
1. Go to the **Keys and Tokens** tab in your app settings.
2. Copy the following credentials for use in SocialVibe:
  - **API Key**
  - **API Secret**
  - **Access Token**
  - **Access Token Secret**

### Step 5: Finalize and Save
1. Once you have completed the setup and entered the credentials in SocialVibe’s platform configuration, save the settings.
